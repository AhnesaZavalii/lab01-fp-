
# Лабораторна робота №1

## Тема
Функціональне програмування в Python.

## Варіант 4
Кошик покупця.

## Опис
Програма обробляє кошик покупця.
Для кожного товару обчислюється початкова вартість,
застосовується категоріальна знижка, купон і ПДВ.

Програма створює нові дані, не змінюючи початковий кошик.

## Використані принципи
- Чисті функції.
- Референційна прозорість.
- Відсутність мутації вхідних даних.
- Функції вищого порядку.
- Callable для типізації функцій.
- Автоматичне тестування через pytest.

## Структура
- core.py — основна логіка.
- app.py — запуск програми.
- tests/test_core.py — автоматичні тести.
- requirements.txt — залежності.

## Запуск
```bash
python app.py
```

## Запуск тестів
```bash
python -m pytest
```

## Перевірка типів
```bash
python -m mypy core.py app.py
```

## Форматування та перевірка стилю
```bash
python -m black core.py app.py tests
python -m ruff check .
```
